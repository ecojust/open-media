# 原创片头片尾背景

这里的十段静音动态视频由 `scripts/generate-video-segments.py` 绘制和编码，归属 Open Media，采用项目的 MIT 许可证。没有使用外部素材、字体或音轨。

视频为 1280 × 720、24 帧/秒、5 秒的 VP9 WebM 文件，可在受支持的桌面系统和浏览器中播放。封面直接取自编码后的视频。标题和副标题由编辑器添加为独立、可编辑的文字片段，视频中不烧录文字。

`manifest.json` 记录视频大小、时长与 SHA-256。运行生成脚本需要 Python、NumPy、Pillow 和 FFmpeg；这只用于维护素材，应用播放和添加素材不需要额外下载。
