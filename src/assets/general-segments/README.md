# 通用片头与片尾

16 款原创动态背景，包含 8 款片头和 8 款片尾。几何、光影、纹理由 `scripts/generate-general-segments.py` 生成，不包含外部视频、人物、品牌标识或固定文字。

- 视频：1280 × 720，24 fps，5 秒，VP9 WebM，无音轨。
- 文字：由应用插入为独立的标题与副标题片段，可继续编辑内容、位置和样式。
- 布局：支持居中、左对齐眉题、下方结语与右侧署名；位置和安全边距随项目画幅调整。
- 时长：素材库可调整为 2 至 12 秒；完整背景动画通过变速适配，保持原始素材完整。
- 校验：`manifest.json` 记录文件大小与 SHA-256；预览图从成品视频抽帧生成。
- 作者与许可：Open Media，MIT。
