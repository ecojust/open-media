# 声音风格头像

`voice-portraits.png` 是为本项目通过图像生成工具制作的风格示意图集。人物均为虚构形象，不代表声线提供者的真实外貌。原始生成图为 1086 × 1448 像素，按 3 列、4 行排列；界面通过背景定位显示相应头像，所有播放与操作按钮仍使用 SVG 图标。

图像实际纵向分界约为 x=362、724，横向分界约为 y=353、702、1051，四行并非严格等高。界面使用 340 × 340 像素的正方形取景：各列起点为 x=11、373、735，各行起点为 y=7、358、707、1080。取景位于每格内部，避开接缝，不露出相邻人物，也不拉伸头像。更换图片后应重新核对分界与取景参数。
