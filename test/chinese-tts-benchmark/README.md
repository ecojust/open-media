## 记录与许可

各模型来源、许可、声音选择、推理参数、运行环境和原始生成清单保存在 `manifests/` 与 `manifest.json`。原始日志、参考音频、来源证据与诊断记录原样保存在 `provenance/`，复制前后均核对 SHA256；该目录包含诊断音频时，不计入正式对比的样本数。 模型名称用于识别实际测试对象，不表示软件已经内置这些模型。样本只代表对应声音与本次参数，其他声音或参数可能得到不同结果。使用已有音频的样本会保留真实复用记录与原次生成耗时，不将复制时间伪装为重新合成时间。
