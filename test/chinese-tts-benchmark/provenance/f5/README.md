# F5-TTS 中文语料实测

本目录保存 F5-TTS v1 Base 的真实离线 CPU 试听（在 GitHub Actions 的 CPU runner 执行）、逐条合成记录和可复现脚本。

- 固定声学模型：`SWivid/F5-TTS`，提交 `84e5a410d9cead4de2f847e7c9369a6440bdfaca`，`F5TTS_v1_Base/model_1250000.safetensors`。
- 固定声码器：`charactr/vocos-mel-24khz`，提交 `0feb3fdd929bcd6649e0e7c5a688cf7dd012ef21`。
- 固定推理源码：`SWivid/F5-TTS`，提交 `2f866649b779881af8bd644e76b9a6d95053da29`。
- 完整必需模型组件：**1,402,816,013 字节**，包含声学权重、词表、声码器权重与配置；不含 Python 运行环境、许可说明及参考音频。
- 使用官方默认的 32 步、CFG 2.0、Euler、sway -1.0、FP32、24 kHz 声码器；CPU 4 线程；01–09 的分句串行运行，第10条在恢复工作流中并行生成3个原始分块后按原顺序拼接。

10 条中文原文来自统一的 `corpus.json`，未人工改写数字、日期、缩写或多音词。保留模型自己的拼音分词和时长估计。运行时不访问云端语音服务，也不使用公开示例音频代替目标语料。

## 参考声音

此模型需要音频参考。`reference.wav` 是之前本地 Matcha 中英女声生成的 8.729 秒语音，仅从 16 kHz 转换至 24 kHz；没有使用任何真人录音。原文、原始及转换后 SHA256 见 `reference.json`。声音特征与语气可能受到此合成参考影响，因此不能将本次一个参考的试听结果当作模型全部能力。

## 结果和复现

合并后的 `manifest.json` 记录统一试听页所需信息；`shards/` 保留各分片原始记录、起止时间、耗时、文字、种子、帧数、WAV/MP3 校验值及进程峰值 RSS。所有文件路径与模型原始 URL、固定提交、字节数、SHA256 见 `sources.json`。

固定提交中的 `f5-benchmark.py` 直接调用原始源码中的 DiT、CFM、分词及 mel 处理。只绕过训练包初始化器，从而避免加载训练、界面和自动语音识别依赖；没有修改模型算法、权重或目标文字。参考响度处理、时长估计、句间交叉淡化与上游推理助手保持一致。

共享环境使用 CPU 版本 `torch==2.9.1+cpu`、`torchaudio==2.9.1+cpu`，额外推理依赖为 `vocos==0.1.0`、`torchdiffeq==0.2.5`、`x-transformers==1.44.4`、`pypinyin==0.55.0`、`rjieba==0.1.13`，具体解析版本见 `requirements-resolved.txt`。没有安装或使用 CUDA。源码和模型文件不放入试听资料包，可按固定来源及 SHA256 重新下载。

01–09 的生成时间包含已加载模型后的分句处理、声码器与拼接，不含首次加载或文件编码。第10条记3个恢复分片推理时间之和，并非并行墙钟时间。不同模型或分片可能使用不同执行环境和负载，不能据此作严格性能排名。峰值RSS是已保存记录中观测到的单个进程最大值，不是并发机器内存之和。

原始运行39048766863的第10条实际生成完成，但峰值1.0092947483062744触发保存前检查，导致没有保存该条WAV。恢复运行39051471837保留相同32步、FP32、种子、参考声音和分块时长，只重生成该条3个分块。01–09保留原PCM16字节；第10条原分块与拼接结果使用FLOAT WAV，保留超满量程数值，不调整增益或截幅。逐条格式、两次来源、峰值和超满量程数量见manifest；原分块与失败日志保留以便核验。MP3只是128kbps有损试听派生，没有额外调速、变调、去噪或响度处理。
