# Open Media

本地录屏、视频剪辑、分段动图与媒体转换工作台。通过左侧工作区切换任务，在同一个项目中管理录制片段、视频、音频和图片。

## 工作区

| 工作区 | 功能 |
| --- | --- |
| 屏幕录制 | 点击开始后交互选择窗口、整屏或拖动框选区域，调整输出尺寸；红框标示范围，支持暂停、继续及快捷键截屏 |
| 分段 GIF | 设置多个时间区间，按片段生成动图，调整输出尺寸、帧率和循环方式 |
| 视频剪辑 | 多轨时间线、片段滤镜、裁切与分割、拖动编排、速度、音量、画面布局、文字叠加、动态水印与绿幕去底、离线多音色配音与单独试听 |
| 视频转换 | 转换 MP4、MOV、MKV、WebM，调整输出尺寸、帧率和码率，也可提取音频 |
| 图片转换 | 批量转换 PNG、JPEG、WebP、BMP、ICO、静态 GIF、TIFF；像素刻度框选裁剪，调整尺寸、质量、旋转、翻转和背景 |

素材保留原文件。编辑项目保存素材与剪辑信息，导出生成新的媒体文件；两者用途不同。转换队列显示每项结果，支持取消及下载已完成结果。界面操作图标统一使用 SVG。

右上角提供浅色、深色和跟随系统三个并列主题按钮，当前选项会高亮。

视频剪辑中的**保存**（Ctrl/⌘+S）首次选择位置，之后直接覆盖当前项目文件；通过“打开”载入的文件也可直接保存。**另存为**（Ctrl/⌘+Shift+S）每次选择位置，成功后后续保存写回新文件。取消或写入失败不会切换当前保存位置。自动保存仍只保留本地草稿；从草稿恢复或新建项目后，首次手动保存重新选择文件位置。网页版在支持本地文件访问的浏览器中使用相同方式，其他浏览器下载项目副本。

桌面端关闭窗口或退出应用时，如果项目尚未保存到文件，会提供“取消”“全部关闭”和“保存并全部关闭”。全部关闭不再保存当前修改，已保存的本地草稿保留；保存取消或失败时继续留在工作区。进行中的录制、配音、转换和导出需先完成或取消，待恢复的录制文件需先保存。确认退出后关闭整个应用并释放相关资源。

## 使用

1. 点击“导入素材”或将文件拖入窗口；也可以进入“录屏”，点击开始并完成系统授权，在选择界面确认范围与尺寸后录制，停止后结果会加入素材库。
2. 在“视频剪辑”中双击素材或拖入时间线。拖动片段调整位置，拖动两端裁切，在播放头处分割；选中片段后调整速度、音量、布局和淡入淡出。文字放在独立轨道，可以与视频、图片和音频一起编排。
3. 点击“导出视频”选择输出参数；只需要片段动图时，进入“片段转 GIF”设置一个或多个起止区间，再选择尺寸、帧率和循环方式。
4. 图片和视频转换可直接选取素材库中的文件，设置参数后加入队列。每项任务单独显示进度和结果，可以取消尚未完成的处理。

视频剪辑工作区“保存”旁的**自动保存**开关只保留当前设备的本地草稿，可从开始页的最近项目恢复。点击**保存**会生成 `.omedia` 项目文件，其中包含编辑信息和素材原件，可以迁移到另一台设备后继续编辑。原始素材总计不超过 256 MB 时可以打包便携项目；此限制不影响桌面视频导出。自动保存不会持续改写已经保存到磁盘的项目文件。

**保存项目与导出媒体是两个操作。** `.omedia` 用于后续编辑；视频、图片和动图导出生成新的媒体文件，不改动原件。

| 环境 | 录制与处理方式 |
| --- | --- |
| 桌面端 | 安装包自带媒体处理能力，支持本机录制和多种视频、音频格式的离线渲染、转换；无需手动安装额外媒体工具 |
| 网页端 | 支持浏览器提供的屏幕采集、剪辑预览、动图和常用图片转换；视频以 WebM 实时导出，处理时间随播放时长变化，导出时需保持窗口在前台 |

具体格式以界面可选项为准。桌面端遇到原生预览无法直接播放的受支持素材时，会保留原件并生成兼容预览；无法解码的素材会显示错误。不同设备和浏览器的解码能力不同，不保证任意媒体文件都能打开。

屏幕或麦克风仅在点击开始并完成系统授权后采集。桌面端录制来源由操作系统可用设备决定；网页端由来源选择器决定是否包含共享音频。macOS 首次录制可能需要在系统隐私设置中允许屏幕录制和麦克风访问。

### 剪辑录音

视频剪辑预览区的播放按钮后提供麦克风录音按钮。点击后授权麦克风，再次点击停止；录音从开始时的播放头位置加入“配音轨道”，同时保留在素材库中，可试听、裁剪、撤销及随项目保存。已有同名轨道未锁定、未静音且对应时段空闲时会复用，否则新建同名音频轨道，保留已有内容。

录音按钮旁可选择麦克风来源，选择会自动记住。实际开始录音后，画面与播放头从当前刻度同步前进；超过原片尾时保留最后画面，录音仍插入开始时的位置。录音期间暂时锁定编辑和工作区切换，结束后释放麦克风。等待授权时可以取消；添加失败时可重试或单独保存录音文件。单段录音满 30 分钟或已收集音频达到约 96 MiB 时自动结束并加入项目。

### 水印与动态素材

时间线工具栏中，**字幕**右侧的**添加水印**会打开素材库。内置 18 个原创动态素材，分为互动贴纸、装饰动效、提示标注和字幕标签，支持分类、搜索与静音预览；也可以导入自己的图片或视频。

点击素材的加号，从打开素材库时的播放头位置添加到独立的**水印轨道**，叠加在原画面上。已有轨道的对应时段被占用或已锁定时，会新建轨道。内置绿幕动画自动去除绿色背景；选中片段后可在右侧属性调整位置、大小、透明度和裁剪时长，也可开启或调整**绿幕去底**的颜色、容差及边缘柔和程度。

水印可随时间线编辑、撤销和重做，素材原件与去底参数随项目保存；网页及桌面导出均包含动态叠加和透明效果。内置动画每段为 4 秒，提供 MP4 与 WebM 两种格式，浏览器按解码能力自动选择。素材来源与生成说明见 [内置水印素材](public/watermarks/README.md)。

### 录制范围与尺寸

- 点击**开始录制**后进入选择界面：**屏幕**选择整块显示器，**窗口**悬停高亮后点击选择，**区域**在桌面拖动框选。支持拖动选区、拉动边角缩放、调整像素宽高及方向键微调，确认后才开始录制；按 Esc 可取消。
- 选区界面显示实际像素尺寸，高分屏会换算为物理像素。多显示器分别提供选择界面，区域限制在当前显示器内。
- 输出可选原始尺寸、1920 × 1080、1280 × 720 或自定义偶数尺寸。指定尺寸时保持内容比例，多余空间留黑边。桌面原始尺寸会对齐编码所需的偶数像素，超大来源缩放至支持范围内；实际输出尺寸在录制时显示。
- 桌面端红框标示实际录制范围，随所选窗口移动，暂停或停止时消失。窗口关闭、最小化或录制范围不可用时暂停并提示原因，不会改录整个桌面。暂停后继续录制沿用首次确定的输出尺寸。
- 红框右上方的悬浮操作栏显示已录制时长，提供暂停／继续、麦克风开关和停止按钮；暂停期间保留操作栏且计时冻结，停止成功后自动收起并将结果加入素材库。屏幕边缘会自动调整位置，避免按钮超出屏幕。
- 选择范围的面板默认开启麦克风，可在确认前关闭；麦克风开关、取消和开始按钮放在同一面板内。录制或暂停时仍可开启／关闭麦克风，关闭会释放设备，首次开启按系统要求授权。网页端麦克风与共享音频独立控制。
- 桌面端切换麦克风会短暂切换录制片段，停止时自动合并并为无麦克风片段补齐静音；授权预检期间原画面继续录制。开启失败会保留原录制，等待授权期间也可停止。
- macOS 屏幕录制会排除录制控制栏，并保留开始录制时已有的本应用普通窗口；录制期间新开的本应用原生窗口不会自动加入当前捕获范围。
- 桌面红框排除需要 Windows 10 2004（系统内部版本 19041）或更新系统；macOS 桌面录制需要 13.0 或更新系统。
- 打开录屏工作区不会请求设备权限；点击开始后查询当前可用来源，确认范围后再开启麦克风和倒计时。取消选择会清理临时窗口与采集资源。
- 网页端先通过系统共享选择器授权，再在来源预览上交互选择范围和尺寸；区域录制必须选择整个屏幕。网页预览显示红框，其他窗口上的共享指示由浏览器控制；红框不会写入导出画面。网页使用自定义尺寸或区域录制时，请保持工作台在前台，以免后台限速影响录制帧率。

### 时间线整理

顶部提供主题切换与应用信息，应用信息显示版本号及构建时间。新建与打开位于开始页，保存、自动保存及撤销重做位于剪辑工作区；项目设置通过“导出视频”旁的图标打开。桌面媒体处理任务可从底部状态栏查看。

- 分割、裁剪、字幕等工具集中在时间线工具栏。拖动预览与时间线之间的分隔条可以调整上下区域高度；素材过多时列表独立滚动，卡片保持原有高度。
- 在片段内部定位播放头，用 **Q** 裁掉左侧、**W** 裁掉右侧；按原素材时间和变速比例计算，至少保留一帧。
- 右键视频、音频或文字片段，可以分割、复制、删除；文字额外提供配音与语音对齐，视频可分离音轨。
- **删除并接拢空隙**会删除当前片段，并压缩该时段内所有轨道共同空白的部分；其他轨道仍有内容的时段保持原样。**清除公共空隙**用于整理整条时间线，字幕、配音和画面同步前移。
- 时间线提供吸附开关，移动片段或裁切边缘时吸附到最近的片段边缘或播放头，并显示参考线。按住 **Shift** 可临时忽略吸附，仍按项目帧率对齐。
- 拖动轨道名称旁的手柄可上下排序，插入线显示放置位置，靠近时间线边缘时自动滚动；按 **Esc** 可取消。排在上方的画面轨道显示在前景，预览与导出使用相同顺序，片段时间保持不变。选中手柄后也可用 **Alt + ↑ / ↓** 调整顺序，支持撤销、重做与项目保存。
- 双击轨道名称可以重命名；轨道菜单支持调整上下层级、移除空轨或确认后删除整轨。锁定轨道需先解锁才能拖动，所有修改可撤销。

### 片段滤镜与试听

- 选中视频或图片片段，在右侧切换到**滤镜**：提供含原色在内的 12 种预设，可调整强度、亮度、对比度、饱和度、色温、色调和复古效果。关闭滤镜可对比原片，重置可清除调整。滤镜只影响当前片段，预览与导出均保留效果，并支持保存与撤销。
- 选中配音或音频片段，点击右侧属性中的**播放图标**即可试听，再次点击暂停，也可拖动进度定位。试听沿用当前片段的裁剪范围、速度、音量与淡入淡出，不受轨道静音影响；开始试听会暂停主时间线，恢复主时间线播放会停止试听。音频自行连续播放，界面刷新只读取播放进度。

### 截屏

点击屏幕录制页顶部的 **截屏设置**，在弹窗中设置快捷键，默认使用 **Command/Ctrl + Shift + 2**，也可点击**立即截屏**。选择范围并确认后，图片自动加入素材库，打开图片转换并选中刚截取的图片。

桌面端快捷键在应用运行时全局生效；网页端仅在当前网页获得焦点时生效，并需要通过系统共享选择器授权。取消选择会释放采集资源。

### 图片框选与格式转换

在图片预览上点击**框选裁剪**，拖动选择范围，使用八个边角手柄调整尺寸，或切换到移动工具调整位置。顶部和左侧标尺以原始图片像素显示，支持细分网格、1–100 px 吸附步长及最高 800% 放大；X、Y、宽、高可直接输入整数像素。方向键移动 1 px，按住 Shift 移动 10 px。点击**应用裁剪**保存这张图片的范围，取消则保留之前设置；批量转换时，每张图片使用各自范围，先裁剪，再缩放、旋转和翻转。

ICO 支持在一个文件中包含 16、32、48、64、128、256 px 中选定的尺寸，保持图像比例并居中。静态 GIF 使用自适应调色板，半透明像素转为透明或不透明；TIFF 保存未压缩的 RGBA 像素。AVIF 只在当前环境实际支持编码时显示。ICO 与 TIFF 的结果保留在转换队列，可单独下载或打包保存，预览采用兼容图片，下载文件保持所选格式。

### 文字转语音

桌面安装包附带独立离线语音模型，声音列表精简为 25 个代表音色：中文男声 10 个、中文女声 12 个、英文女声 3 个，无需使用系统语音、申请服务密钥或上传文字。在视频剪辑中点击**配音**打开弹窗，通过带风格头像和音色类型标签的分类卡片选择声音，可按名称或类型搜索。点击卡片喇叭会播放对应语言的固定示例，再次点击暂停；试听无需填写文字。公共配音弹窗提供音色、语速设置以及全部文字的生成与对齐操作。选中文字片段后，在右侧属性点击**文字转语音**或**对齐语音**直接执行，不会打开弹窗；右键文字片段也可生成语音。单片段生成状态、取消和错误提示显示在右侧属性中。

- 25 个代表音色各自附带本地试听音频，首次点击、切换声音或重新打开软件均无需重新合成；调节试听语速会直接改变播放速度并保持音高。历史项目中未提供固定试听的其他声音仍使用离线合成。
- **文字时长对齐语音**默认开启：保持文字起点，按实际音频时长调整文字显示时间。关闭后保留原文字时长。
- 语音放入独立配音轨，进入素材库，可继续裁切、调整音量和随视频导出。重新生成会替换该文字的关联配音；整批操作可一次撤销。
- 后续裁切、移动或调整语音速度后，可用**文字对齐已有语音**重新同步。修改文字内容后需重新生成配音。
- 批量按时间顺序处理，显示完成数量与当前进度，可随时取消。取消或生成失败不会写入部分时间线结果；空文字、锁定轨道和超长文字会显示跳过原因。
- 每段最多 4000 个字符。配音重叠时会提示，并保留原有片段起点，避免挪动其他素材；可在时间线中调整。

网页端可以编辑、播放和导出项目中已有的配音；新增离线配音需使用桌面端。语音资源的来源、许可与开发准备见[语音运行时说明](docs/SPEECH_RUNTIME.md)。

### macOS 授权与启动提示

首次点击开始时，按系统提示允许屏幕录制；启用麦克风时另需麦克风访问权限。授权或更新应用后，如果系统要求重新打开，请完全退出应用，再从“应用程序”中的同一份应用重新启动。

应用会分别提示来源授权、麦克风、编码器、录制边框和首帧启动失败，并保留系统错误信息。若已授权仍失败，请以界面显示的具体错误定位；权限设置中存在勾选项并不能说明当前运行的安装副本已被系统认可。

可以覆盖安装升级，无需先卸载。当前安装包使用临时签名，替换应用后系统可能不再接受旧副本的屏幕录制授权。如果升级后出现 `SCStreamErrorDomain -3801`，请完全退出应用，在系统设置的屏幕录制权限中移除旧条目，重新添加并允许 `/Applications/Open Media.app`，再打开应用。仍然失败时，可在退出应用后运行以下命令，仅重置本应用的屏幕录制授权，然后重新打开并授权；项目文件不会被删除：

```sh
tccutil reset ScreenCapture com.ecojust.openmedia
```

录屏实现直接链接在主程序中。若旧版报错包含 `dlopen` 或 `different Team IDs`，表示录屏组件加载被系统拒绝，尚未进入屏幕权限检查；应使用修复后的完整应用包。

## 开发

前端需要 Node.js 24：

```sh
npm ci
npm run dev
```

桌面开发还需要 Rust 和目标平台的桌面构建依赖。首次构建先准备媒体工具，具体前置工具见 [媒体运行时说明](docs/MEDIA_RUNTIME.md)：

```sh
npm run runtime:prepare
bash scripts/build-media-runtime.sh
npm run speech:prepare
npm run desktop:dev
```

```sh
npm test
npm run build
npm run test:browser
cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --locked --lib
```

媒体验证会真正编码和读取视频、音频及图片；录屏设备授权仍需在目标桌面系统上实际确认。流水线构建 Windows x64、macOS ARM64 和 macOS x64 安装包，发布要求同一提交的全部必要任务通过。

录屏专项检查通过 `capture-macos.yml` 在 macOS ARM64 构建机上安装完整应用，分别验证带红框和不带红框的真实屏幕采集，并保留系统版本、签名、测试日志和录制文件。该流程直接启动录制模式，可能继承构建机执行代理的授权，不能证明应用升级后的旧授权仍然有效。`capture-gui-macos.yml` 则原样安装已有正式包，通过应用启动器和真实界面发起录制，分别报告成功录制、系统拒绝授权和自动化操作受限；不会重新签名或修改权限数据库。设备授权被拒绝时测试失败；编解码自测通过不等于屏幕采集通过。命令说明见[录屏组件说明](src-tauri/resources/capture/README.txt)。

已完成的环境、结果和覆盖范围见[录屏专项验证记录](docs/RECORDING_CHECK.md)。
