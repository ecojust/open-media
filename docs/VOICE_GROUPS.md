# 音色候选精简分析

> 历史分析记录：以下数据对应旧版多音色模型，不代表当前配音列表。当前版本使用一种支持中英混合的温柔女声，资源与参数见[语音运行时说明](SPEECH_RUNTIME.md)。旧项目已经生成的音频继续保留，重新生成使用当前音色。

全部 103 条实际声音与权重均不完全相同。以下方案用于减少默认候选，不声称它们是同一人或感知上完全相同的声音。仅精简候选目录，旧项目声音 ID 和模型资源必须保留。

默认保留 25 个代表：中文男声 10、中文女声 12、英文女声 3。保留原全局默认 zf_001。

## 可复现方法

从锁定的 voices.bin 读取 103×510×256 的 float32 权重，对 510 个长度位置取均值，比较 256 维向量的余弦相似度。另读取所有真实同文 WAV，计算活动帧的 MFCC 统计。中文男、女分别标准化特征，避免仅凭音高、名称或分类删除声音。

每个非代表音色必须直接满足与代表的两个条件：权重余弦 ≥ 0.70，标准化 MFCC 距离 ≤ 1.40。贪心选择覆盖最多尚未覆盖音色的代表；相同覆盖量时比较余弦总和，再按原 speakerId 排序。最终各声音分配给符合条件且余弦最高的代表，不通过 A 类似 B、B 类似 C 的链式关系把 A 归给 C。

固定阈值用于工程上的默认候选整理，并非经过人类盲听验证的相似音色阈值。没有自动修改原有声音。

## 结果与边界

最差代表余弦：0.700048（zm_080）。最大代表 MFCC 距离：1.38859（zm_095）。

权重距离与音频频谱距离的 Spearman 相关：中文女声 0.575、中文男声 0.480，仅为中等相关，不足以单独证明听感相同。

风格覆盖：男声低沉 4、明亮 3、舒缓 1、自然 2；女声清亮 5、低沉 5、自然 2；英文自然 2、成熟 1。原女声的舒缓样本被其他代表覆盖，未为风格数量强行更改分组。

音频使用历史静音保留比例 0.2、1 倍语速、24 kHz 单声道；当前生成器使用 1.0，不能将历史句长当作当前合成时长。该分析未进行人工盲听，没有使用专门的说话人识别模型，不保证所有语气、口音和长文本表达都被保留。

## 应用行为

`src/core/voice-groups.ts` 保存精简分组；`compactVoiceCatalog` 仅整理选择面板。首次打开从精简目录选择中文声音，分类计数、搜索、卡片和试听使用一致的列表。原生清单及合成入口继续保留原始 103 个 ID，不裁剪模型资源，不减少安装包大小。

当前已选音色若属于被收起的成员，则显示它并收起本组默认代表，不自动替用户换声音。自定义音色以及语言或性别与分组不匹配的条目保留；缺少默认代表时保留本组仍可用的声音。原有项目的声音 ID、音频和字幕时长无需迁移。
