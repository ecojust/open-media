## 拍摄范围

图片直接截取当前源码运行的完整应用，未拼接界面或替换控件。录屏和图片编辑使用网页模式；剪辑、视频列表及生成工作区使用桌面接口演示数据呈现对应布局，因此主题控件位置会随运行环境不同。信息弹窗如实显示开发模式。

- 录屏示例以程序内绘制的画布作为来源，经过实际录制、停止、编码和解码检查，得到 1280 × 720 视频；没有采集用户屏幕或设备麦克风。
- 图片编辑使用实际 PNG 输入，文字和笔触由当前画布渲染；剪辑工程使用仓库内的原创动态视频及音频，经过本地保存与重新加载。
- 视频列表中的目录和桌面平台信息为演示接口数据，列出的示例媒体实际可解码。截图展示截取与转换配置，不表示原生转码已经完成。
- 生成工作区中的可选模型均显示待下载。模型目录来自仓库清单，截图展示输入配置，不包含伪造的生成结果，也不代表完整模型推理测试。
- MCP 配置使用公开的示例 Token，未启动服务、连接外部客户端或模拟操作成功。

## 复现

安装项目开发依赖后，在仓库根目录依次运行；脚本只生成演示媒体和截图，不下载模型、不调用用户的屏幕或麦克风设备：

```sh
node scripts/screenshots-record.cjs
node scripts/screenshots-libraries.cjs
node scripts/screenshots-ai.cjs
node scripts/screenshots-image.cjs
node scripts/screenshots-editor.cjs
```

需要本地浏览器；视频列表脚本还需要媒体编码命令。各脚本启动临时开发服务，结束时释放浏览器与服务。

## 风格成片截图

新增 `motion-style-light.png` 与 `motion-style-dark.png` 对应 v0.3.4 的风格成片界面，尺寸为 1440 × 1100。`motion-style-gallery.png` 展示同一组素材在实际时间线中生成的 15 种横屏画面。

```sh
node tests/browser/motion-style-ui.cjs
node tests/browser/motion-style-render.cjs
```

两项使用本地示例图片、视频和配乐，分别验证界面操作与实际合成，不调用录屏或麦克风。脚本在临时目录写出截图、可解码的视频和原生导出测试工程；设置 `BROWSER_ARTIFACTS` 可指定报告位置。
