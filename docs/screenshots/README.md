# 功能截图

截图基于 Open Media 0.1.11，拍摄日期为 2026-10-17。主界面示例使用同一组旅行素材，包含浅色、深色两套主题，README 根据页面主题选择显示。

| 图片 | 展示内容 |
| --- | --- |
| `editor-light.png` / `editor-dark.png` | 40 秒短片，10 个素材、8 条轨道、28 个片段；标题、字幕、文字水印、动态水印、画中画、旁白、配乐和滤镜 |
| `record-light.png` / `record-dark.png` | 实际录制自建旅行拍摄计划页面，展示红框、计时、暂停、停止及最近的视频素材 |
| `record-picker.png` | 实际来源预览与输出尺寸选择，麦克风在本示例中关闭 |
| `gif-light.png` / `gif-dark.png` | 四个截取区间，实际生成 640 × 360、72 帧、6 秒循环 GIF |
| `video-convert-light.png` / `video-convert-dark.png` | 四个视频的实际批量转换结果及分辨率、帧率、码率与区间设置 |
| `watermarks-light.png` / `watermarks-dark.png` | 500 个水印的分类、搜索、分页与素材卡片 |
| `text-watermarks-light.png` / `text-watermarks-dark.png` | 100 个可编辑文字水印模板 |
| `image-edit-light.png` / `image-edit-dark.png` | 六个输入图片、十段文字、五条笔触及三个实际 WebP 导出结果 |
| `image-tools-light.png` / `image-tools-dark.png` | 文字与笔触编辑弹窗、荧光笔透明度、虚线路线及画笔标注 |
| `image-crop-light.png` / `image-crop-dark.png` | 像素标尺、100% 缩放、20 像素网格吸附及选区坐标 |

所有图片均直接截取当前应用界面。GIF、视频转换和图片编辑中的完成结果经过实际编码、解码检查；录屏示例使用浏览器真实页面采集，停止后得到 1280 × 720 视频。示例没有采集设备麦克风。

`workbench-*` 为早期工作台截图，保留供历史文档引用，本次功能展示使用上表图片。
