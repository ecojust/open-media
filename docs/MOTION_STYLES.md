# MCP 素材二创

在 MCP 弹窗中开启“素材二创”，选择当前工程素材与视觉风格，也可补充创作目标。外部 Agent 接到用户指令后读取这些配置，分析画面内容，规划分镜、文案与节奏，再调用 Open Media 的本地渲染和剪辑工具完成视频。

配置随当前工程保存。开启选项只准备创作配置，不会自动分析、渲染或开始任务；需要用户在连接的 Agent 中提出创作要求。策划使用 Agent 自身的大语言模型，Open Media 负责提供素材读取、画面合成与时间线编辑能力，无须为这项功能下载额外的策划模型。

效果视频编码完成后加入项目素材，可以作为普通视频继续分割、裁切、调速、叠加字幕和添加转场。画面沿用当前工程的尺寸与帧率，源文件保留。

## 从素材到成片

1. 在视频剪辑中导入素材，进入 MCP 弹窗启用素材二创，选择图片或视频、视觉风格并填写可选目标，例如“制作一段面向初学者的产品介绍，突出三个操作步骤”。
2. 向连接的 Agent 发起任务。Agent 读取工程配置，通过素材信息、取帧等接口理解内容，决定素材顺序、源起点、文案与每镜时长。
3. Agent 先检查分镜方案，再调用渲染工具生成效果视频；完成后获得视频素材 ID。
4. Agent 使用普通剪辑工具将视频放到时间线，继续添加字幕、配音、音乐、转场，并通过预览检查效果。用户也可以接手编辑。

单次渲染支持 1–16 镜，每镜默认 4 秒，可设置为 2–12 秒。视频剩余时间不足时按实际长度缩短，保持原速，并返回提示。渲染工具支持背景、强调与文字配色，舒缓、均衡、轻快三档节奏，以及标志图片、背景音乐和原声控制；这些参数由 Agent 按任务要求组织。

文字、说明、装饰和动画已编码到效果视频画面中，不是独立字幕或图层；需要修改这些内容时，调整分镜或风格参数后重新生成。效果视频进入时间线后，编辑方式与其他视频片段一致。

## 15 种风格

| 风格 | MCP 标识 | 画面与运动特点 |
| --- | --- | --- |
| 纸感手绘 | `paper-ink` | 纸张颗粒、铅笔线框与逐格轻摆，适合手作、生活和温暖叙事。 |
| 等轴卡片 | `iso-cards` | 等轴网格、层叠基座与弹性升起，展示产品模块和信息结构。 |
| 扁平跃动 | `flat-pop` | 大胆色块、圆点与弹性入场，让素材在清晰构图中接力。 |
| 极简线描 | `line-focus` | 细线、圆环与留白，配合轻缓平移和标题揭示。 |
| 柔光立体 | `studio-depth` | 柔光球体、层次阴影和悬浮卡片，形成产品展台的空间感。 |
| 柔形律动 | `shape-rhythm` | 圆弧、胶囊与缩放呼应，以图形节奏连接素材和文字。 |
| 知识贴纸 | `sticker-notes` | 白边卡片、网格和重点标签，适合讲解、步骤和知识总结。 |
| 科技视窗 | `tech-hud` | 精细网格、定位括角与环形标尺，突出数据和操作画面。 |
| 杂志拼贴 | `editorial-collage` | 撕纸、半调点阵与错位叠层，给照片和观点鲜明的版面节奏。 |
| 极光玻璃 | `aurora-glass` | 弥散光斑、透明面板和轻缓漂移，适合科技介绍与视觉展示。 |
| 几何构成 | `geometric-grid` | 圆、方块和网格按节奏错位，强调秩序与色彩对比。 |
| 霓虹复古 | `neon-retro` | 落日光晕、透视网格与霓虹色带，营造复古电子气氛。 |
| 像素节拍 | `pixel-arcade` | 像素边框、阶梯色块与离散步进，适合游戏和轻快记录。 |
| 流彩色团 | `liquid-color` | 色团交错与呼吸缩放，让素材随有机节奏出现。 |
| 活力花字 | `expressive-type` | 醒目标题、放射贴片和弹性强调，适合人物、日常和轻松表达。 |

这些风格使用二维图层、预绘光影与关键帧组合：等轴与柔光风格不生成三维模型；柔形风格不改变素材的连续轮廓；流彩不执行流体模拟，玻璃也不计算逐帧折射。像素与贴纸装饰保留源素材本身的内容。

## MCP 调用

Agent 先调用 `open_media_motion_brief_get` 读取当前工程配置，再结合 `open_media_motion_style_list` 查询风格、配色与能力说明。配置查询同步返回 `enabled`、`ready`、`errors`、素材、风格、创作目标及工程版本；功能未启用时也可读取，但不能执行生成。配置只能由用户在 MCP 弹窗修改。

`open_media_motion_clip_generate` 接收 Agent 组织好的分镜，检查方案或编码效果视频；它不负责调用大语言模型生成创意。场景只能引用用户选定的图片或视频，标志图片也必须从这些所选素材中的图片取用。`musicAssetId` 可引用当前工程已有的音频，音乐不列在二创视觉素材选择器中。`styleId` 可省略并沿用用户选定风格，不能由 Agent 换成其他风格。

先读取用户配置：

```json
{
  "name": "open_media_motion_brief_get",
  "arguments": {}
}
```

假设用户已启用素材二创、选择科技视窗风格，并勾选示例中的图片、视频与标志图片；配乐音频已导入当前工程。Agent 分析后准备了两镜介绍短片，此示例先检查方案。占位 ID 和工程版本必须替换为实际值；无需配乐或标志时省略对应字段。

```json
{
  "name": "open_media_motion_clip_generate",
  "arguments": {
    "styleId": "tech-hud",
    "title": "从问题到发现",
    "scenes": [
      {
        "assetId": "image-asset-id",
        "heading": "提出问题",
        "caption": "用一张图片建立主题和观察重点。",
        "duration": 4
      },
      {
        "assetId": "video-asset-id",
        "trimIn": 1,
        "heading": "观察变化",
        "caption": "用实际画面解释过程与结论。",
        "duration": 5
      }
    ],
    "destination": "assets",
    "tempo": "balanced",
    "accent": "#5BE2DA",
    "background": "#0A1925",
    "textColor": "#E2F6F5",
    "musicAssetId": "audio-asset-id",
    "musicVolume": 0.2,
    "logoAssetId": "logo-image-asset-id",
    "sourceAudio": false,
    "dryRun": true,
    "expectedProjectId": "current-project-id",
    "expectedRevision": 12
  }
}
```

`dryRun: true` 只校验并返回每镜起止时间、实际时长、配色和提示，不创建素材或修改轨道。确认方案后，用相同参数将 `dryRun` 改为 `false` 执行；工程版本应使用调用时的实际版本。

两种调用都会返回任务 ID，通过 `open_media_job_get({"id":"返回的任务 ID"})` 查询进度与结果，也可用 `open_media_job_cancel` 取消。正式生成完成后，结果包含视频的 `assetId`、来源 `sourceAssetIds`、实际时长、尺寸与 `warnings`。使用该 `assetId` 调用普通片段添加工具，即可选择轨道和时间位置。

`destination` 默认为 `assets`，只将效果视频加入项目素材。需要同时放入时间线时，可设置 `destination: "timeline"`，并用 `insert` 指定 `trackId` 和 `start`；生成视频会作为一个普通片段加入。生成时会校验当前工程与版本，整次提交可一步撤销。

完整连接方式、素材导入和任务约定见 [MCP 文档](MCP.md)。
