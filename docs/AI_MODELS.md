# 共享 AI 模型

模型管理属于主应用。主侧栏的“AI 模型中心”在每个工作区都可打开，统一显示配音、视频、图像和歌曲模型，以及下载、校验和推理任务。模型只安装一份，切换工作区不会终止下载或生成。

## 模型能力

| 模型 | 能力 | 模型下载量 |
| --- | --- | --- |
| Qwen-Image | 文生图、基于原图重绘 | 57,704,575,013 字节，约 57.70 GB |
| Z-Image-Turbo | 快速文生图、基于原图重绘 | 32,848,305,533 字节，约 32.85 GB |
| ACE-Step 1.5 Turbo | 快速歌词歌曲、纯音乐 | 约 6.34 GB |
| ACE-Step 1.5 SFT | 标准歌词歌曲、纯音乐 | 约 6.34 GB |

同一文件按内容校验后共享缓存；两种歌曲模型的文本编码器和音频解码器可复用，因此同时安装的实际新增下载量小于两个模型总量。运行环境单独下载，解压后的占用与临时输出还需要额外磁盘空间。

图像重绘使用原图和提示词控制整体生成，不承诺专用指令编辑能力。快速图像模型使用零引导强度，不展示无效的负向提示词控制。歌曲生成需要用户提供歌词；纯音乐不需要歌词。当前歌曲模式不自动编写歌词，也不会暗中下载用于内容规划的额外语言模型。

## 设备与内存

新增图像和歌曲运行环境与既有配音环境隔离，避免依赖版本更新使已下载音色失效。Windows、Linux 使用支持 CUDA 的运行环境并检测实际设备，Apple 芯片使用可用的 MPS；无法使用 GPU 时会报告原因并尝试 CPU。新生成运行环境要求 Apple 芯片 Mac 的系统至少为 macOS 14，Intel Mac 暂无兼容的新生成环境，既有剪辑及配音功能保留。视频生成仍使用其独立的 Apple 芯片原生后端，不代表视频模型本身只能运行于该硬件。

低内存模式减少 GPU 权重驻留，不等同于所有模型都具备 SSD 流式推理。图像模型仍需相应的系统或统一内存，CPU 使用全精度时占用可能更高。尤其 Qwen-Image 的完整半精度权重已超过 32 GB，不应据此承诺 32 GB 设备可顺利生成。建议先使用较小画幅、短音乐和更轻的模型；具体速度与峰值内存须在目标设备实测。

共享推理队列将不同工作区的模型推理串行执行，避免配音、图像、歌曲和大模型视频同时装载。排队任务可以取消，下载不占用推理队列。失败或取消的生成结果不会加入工程；正常完成后，结果经真实媒体验证，再由用户或 MCP 明确加入素材／时间线。

## 下载与兼容

下载清单固定模型版本、每个文件大小及 SHA-256，提供官方来源和镜像，并支持部分下载保留、续传与完整性检查。仅通过校验的完整安装会标为就绪。模型中心可检查或修复已安装版本，运行组件按独立版本安装，不覆盖旧配音环境。

既有配音与视频模型目录、声音 ID 和任务历史保持兼容。原配音及视频 MCP 工具继续使用同一管理器；新增全局模型工具及图像／歌曲工具见 [MCP 说明](MCP.md)。

## 来源与验证范围

图像模型采用 Apache-2.0，歌曲引擎及模型采用 MIT，并保留所含编码器的原始许可。固定版本与原始文本记录在 `licenses/ai-generation/`，模型文件清单位于 `src-tauri/resources/ai-image-models.json` 和 `ai-music-models.json`。

交互、协议、下载与任务测试不等于完整模型推理。运行环境检查覆盖依赖导入、离线搬迁、实际可用设备的小型计算以及图片／音频文件读写；完整权重生成的画质、音质、耗时与峰值内存仍需独立实测，不能用模拟任务或小型算子通过替代。
