# 科普标注素材

24 个原创离线素材：16 个动态标注和 8 个可编辑文字模板。与应用采用相同的 MIT 许可证，不包含下载的视频片段、图片、品牌或人物素材。

动态标注包含相对刻度、轨道指示、聚焦括角、目标引线、波形窗口、双向分隔、四步进度、三组示意、坐标投影、纵向测量、分级比例尺、流程分支、曲线轨迹、角度扇区、分层剖面和编号引脚。刻度、图表、波形和轨迹是视觉示意，不代表实测数据。

文字模板覆盖问题、结论、资料来源、公式、概念定义、假设、数值单位和实验步骤。添加后保持原生文本，可修改文字、字体、颜色、位置与尺寸；默认淡入 0.35 秒、淡出 0.2 秒。

动效为 640 × 360、24 fps、4 秒，无声音；提供 H.264 MP4 及 VP9 WebM，自动抠除绿色背景并抑制边缘溢色。标注先出现结构或引线，随后显示说明并留出阅读时间。文字缩略图只展示实际可编辑的文字与文字底色。

`science-manifest.json` 保存每个文件的长度及 SHA-256。动效缩略图由实际编码的 MP4 第 2 秒抽帧生成。生成代码为 `scripts/generate-science-watermarks.py`；媒体解码校验为 `scripts/verify-science-watermarks.py`，检查两个格式的全部帧、时长、透明空间和真实运动。
