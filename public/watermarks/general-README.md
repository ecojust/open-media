# 通用可编辑模板

24 个原创文字布局，可用于任意内容：主副标题、角标、身份介绍、资料来源、署名、章节、步骤、要点清单、对比标签、提示、结论、引述、数值单位、阶段、时间标记、旁注及结尾。

模板使用原生文字片段。文字、字体、字号、颜色、背景、位置、尺寸和时长均可继续调整，没有烘焙进图片的装饰或字幕。添加前可覆盖文字、颜色、背景、时长、位置与动画。配色与内容不绑定具体视频或学科。

八种入退场预设：无动画、淡入淡出、上下左右滑入、轻推近、轻缩回。动画写入原生关键帧，预览与导出使用同一份数据；默认短暂入场后保持稳定阅读，再短暂退场。旧模板与项目保持兼容。

缩略图由 `scripts/generate-general-watermark-posters.mjs` 调用实际 `drawTextClip` 与 `animatedClipAt` 生成，展示原生文字排版和位置。`general-manifest.json` 保存模板定义、文件大小与 SHA-256。本组原创布局与应用使用同一 MIT 许可证。
