# 图像与歌曲生成的独立运行组件

此目录中的构建流程只生成按需下载的运行组件，不构建应用，不包含模型权重，也不会更改既有配音环境。

运行组件标识为 `ai-generation-v1`，首次同时提供 macOS Apple 芯片、Windows x64、Linux x64。macOS 要求 14 或以上；不为 Intel Mac 提供新运行组件。Windows 与 Linux 包含 CUDA 运行库，设备不可用时可以使用 CPU；驱动仍由操作系统提供。构建机没有可用 GPU 时，验证报告会明确标明，不能把 CPU 测试称为 GPU 或完整模型生成验证。

`ai-runtime.lock.json` 锁定解释器、张量库轮子和歌曲推理源代码的来源、大小与 SHA-256。`ai-runtime-requirements.txt` 固定推理依赖版本，构建时执行依赖完整性检查。归档附带安装记录、原始许可证、来源清单和每个文件的哈希；不会从用户计算机借用 Python、媒体工具或开发环境。

应用通过 `src-tauri/resources/ai-runtime-models.json` 读取经过构建验证后的归档信息。此清单只能由真实构建产物生成；构建失败或平台缺失时不能填入猜测的 URL、文件体积或哈希。独立组件发布为预发布，不会替换应用的最新稳定版本。

构建验证包括接口导入、基础张量运算、图片/音频读写、归档逐文件校验、中文及空格路径迁移、禁止网络访问和执行后的内容完整性。它们不加载完整生成模型，不评估成片/成图/音乐质量或设备运行速度。

运行脚本只在 CI 下载锁定的推理源代码；源代码连同许可证安装在此独立解释器的 site-packages 中。应用版本携带图像/音乐适配脚本，允许以后修复参数或进度逻辑时不要求重新下载模型权重。共享运行环境的依赖升级使用新的版本或标识，保持已经下载的语音环境可用。
